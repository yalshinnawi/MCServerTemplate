# ==============================================================================
# NeoForge JVM Memory & Performance Configuration
# ==============================================================================
# Adjust RAM allocation based on your host system:
#   - 8GB RAM PC:   -Xms4G -Xmx6G
#   - 16GB RAM PC:  -Xms4G -Xmx8G (Recommended default)
#   - 32GB+ RAM PC: -Xms6G -Xmx12G
# ==============================================================================
-Xms4G
-Xmx8G

# ==============================================================================
# Java 21 Generational ZGC (Ultra-Low Latency Garbage Collection)
# Eliminates GC pauses and tick stutters for large 300+ modpacks
# ==============================================================================
-XX:+UseZGC
-XX:+ZGenerational
-XX:+AlwaysPreTouch
-XX:+UnlockExperimentalVMOptions
-XX:+DisableExplicitGC
